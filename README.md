# Поиск сцен Okko

Поиск возвращает до пяти фрагментов с таймкодами для RU/EN-запроса. На CUDA работают мультиязычный E5, FAISS и cross-encoder BGE. Окна по репликам Whisper объединяются в выдаче по рангам E5, BM25 и символьных триграмм. Ранжировщик учится на сложных кандидатах из этой выдачи. Повторяющиеся отрезки одного видео подавляются по IoU.

## Запуск

Нужен Linux x86-64, NVIDIA GPU и драйвер с поддержкой CUDA 12.1. Предполагается, что датасет уже распакован в `./data`:

```text
data/
├── transcripts.pkl
├── video_files.csv
├── train/train_qa.csv
└── test/test.csv
```

Пайплайн читает готовые транскрипты Whisper и CSV. Исходные каталоги `videos/`, `audio/` и файл `audio_files.csv` могут лежать рядом. Веса E5 и BGE при первом запуске загружаются из Hugging Face и далее используются локально.

```bash
conda env create -f environment.yml
conda activate okko
python -m okko index
python -m okko train-reranker
python -m okko evaluate
python -m okko predict --out submission.csv
```

Для своего расположения укажите `--data /path/to/data` и `--index /path/to/index`. По умолчанию индекс сохраняется в `./artifacts`. При обновлении каталога соберите индекс в новом каталоге и передайте его в следующие команды.

## Цели и проверка

| Метрика | Цель |
|---|---:|
| VideoRecall@5 | 0.81 |
| SuccessRate@5, IoU ≥ 0.5 | 0.57 |
| Composite Recall, ранги 1–3 | 0.63 |
| p95 после прогрева на CUDA, без индексации | 240 мс |

Это цели для корпуса порядка 3100 вопросов. Замеров на корпусе пока нет. Для сравнения этапов пересобирайте отдельный индекс на каждом коммите и используйте одну и ту же машину. Начиная со второго коммита `evaluate` использует фиксированное разбиение по `question_id`. В финальной версии `--backend flat` сравнивает точный GPU-поиск с IVF, а `--no-cross-encoder` отключает BGE. Для этого режима отдельно выполните `train-reranker --no-cross-encoder`.

Даты коммитов выставлены для реконструкции последовательности этапов.
